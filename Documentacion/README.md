### 📌 Notas de la Entrega Actual (Semana 13)
* **Iterator:** Permite recorrer colecciones de contenido (películas, series, listas) según distintos criterios sin exponer la estructura interna.
* **Mediator:** Centraliza la comunicación entre componentes del reproductor (controles, buffers, red).
* **Memento:** Permite guardar y restaurar estados previos del perfil de recomendación del usuario.
